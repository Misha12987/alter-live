# Alter Live

Симулятор прямого эфира: зрители, комментарии, лайки, подарки и донаты генерирует само приложение. Стили Instagram, TikTok, YouTube и Twitch, ИИ-зрители, которые слышат голос и видят кадр, секретные тапы, наплывы зрителей, итоги эфира.

Открыть: https://misha12987.github.io/alter-live/

На телефоне: открой ссылку в Safari или Chrome, разреши камеру и микрофон, затем «Поделиться» → «На экран Домой», чтобы запускать Alter Live как приложение.

Все зрители и их сообщения вымышленные. Лица на аватарках сгенерированы нейросетью (100,000 Faces, generated.photos), таких людей не существует. Остальные фото на аватарках взяты из набора ImageNet sample images, права на них принадлежат авторам.
